    API reference¶

    Connection¶

    Connection registry.

    • connect(...) only registers settings - clients are created lazily, so importing your models never touches the network.
    • One synchronous MongoClient per alias (thread-safe).
    • One AsyncMongoClient per alias per running event loop (pymongo's async client is bound to its loop), which makes the library safe in FastAPI/uvicorn workers, gRPC aio servers, Django's async_to_sync and pytest-asyncio.
    • Transactions are carried in a ContextVar so every query in the block joins the session automatically, in threads and asyncio tasks alike.

    connect(uri='mongodb://localhost:27017', db=None, *, alias=DEFAULT_ALIAS, **options) ¶

    Register a connection. db defaults to the database in the URI path.

    aggify.connect("mongodb://localhost:27017/shop") aggify.connect("mongodb+srv://...", "analytics", alias="analytics", maxPoolSize=50)

    disconnect(alias=None) ¶

    Close sync clients and forget the registration (async clients: use :func:adisconnect).

    adisconnect(alias=None) async ¶

    Close the async clients of the current loop (and the sync ones), forget registrations.

    aclose_clients(alias=None) async ¶

    Close this loop's async clients but keep the configuration (app shutdown hook).

    Bases: BaseDocument

    A top-level document stored in its own collection.

    ($set values, $unset keys) relative to the state loaded from / saved to the database.

    QuerySet¶

    Bases: Generic[M]

    query property ¶

    Debug view of what will be sent to MongoDB.

    values(*fields, **expressions) ¶

    Rows as dicts. Followed by annotate(<aggregate>) it groups, like Django.

    annotate(*args, **expressions) ¶

    Add computed attributes ($addFields) or, after values(), aggregates ($group).

    search(text, *, language=None, case_sensitive=False) ¶

    Full-text search ($text); needs a text index: Index("title", "body", type="text").

    options(**opts) ¶

    max_time_ms, hint, collation, comment, batch_size, allow_disk_use.

    to_pipeline() ¶

    The aggregation pipeline equivalent of this queryset (extend it with lookup & co.).

    iterator(chunk_size=1000) ¶

    Stream results without caching them.

    distinct(field) ¶

    Distinct values of field for the current filter.

    aggregate(**expressions) ¶

    Aggregate over the whole queryset: aggregate(total=Sum("amount"), n=Count()).

    update(*, upsert=False, **changes) ¶

    Atomic bulk update; returns the number of modified documents.

    delete() ¶

    Bulk delete (no per-document signals, like Django's queryset delete without signals).

    aiterator(chunk_size=1000) async ¶

    Stream results without caching them.

    Pipeline¶

    to_list() ¶

    Plain list of stages, ready for collection.aggregate.

    filter(*args, **kwargs) ¶

    $match. Accepts Q objects and field__lookup=value keywords.

    order_by(*fields) ¶

    $sort: order_by("-created_at", "name"). F("x").desc() also works.

    project(**spec) ¶

    $project: project(name=1, secret=0) or computed project(full=Concat("a", Value(" "), "b")).

    Inclusion and exclusion cannot be mixed (id / _id may be excluded in either mode).

    add_fields(**fields) ¶

    $addFields. Strings are literals, F() references fields.

    group(by=None, **accumulators) ¶

    $group.

    by may be None (one bucket), a field name, a list of names, a {alias: expression} dict or an expression. Keyword arguments are accumulators::

    .group(["status", "country"], n=Count(), revenue=Sum("amount"))

    annotate(*args, **expressions) ¶

    Add computed fields.

    • right after group() aggregates are merged into that $group
    • otherwise it is $addFields

    unwind(path, preserve=False, include_array_index=None) ¶

    $unwind.

    lookup(from_, as_name, *, local_field=None, foreign_field=None, let=None, query=None, pipeline=None, unwind=False, preserve=True) ¶

    $lookup - both the equality form and the let/pipeline form.

    Aggify(User).lookup(Order, "orders", local_field="id", foreign_field="user") Aggify(User).lookup(Order, "paid", let={"uid": F("id")}, ... query=Q(user=Var("uid"), status="paid"))

    count(name='count') ¶

    $count stage (named count as in Mongo; QuerySet.count() runs it).

    replace_root(new_root=None, *, embedded_field=None, merge=None) ¶

    $replaceRoot. replace_root("profile") / replace_root(F(...)) / replace_root("profile", merge={"x": 0}) (defaults merged under the new root).

    redact(condition, then='keep', otherwise='prune', **legacy) ¶

    $redact with $cond: redact(Q(level__lte=2), "descend", "prune").

    set_window_fields(*, partition_by=None, sort_by=None, **output) ¶

    $setWindowFields:

    .set_window_fields(partition_by="user", sort_by={"created_at": 1}, ... running=Sum("amount", window={"documents": ["unbounded", "current"]}), ... rank=Rank())

    out(coll, db=None) ¶

    $out - writes the result to a collection (replacing it). Must be the last stage.

    stage(name, spec, *, allow_javascript=None) ¶

    Append any stage verbatim (Atlas $search, $vectorSearch, $densify ...).

    The stage is scanned for server-side JavaScript; the scope becomes open (unknown fields are accepted afterwards) because Aggify cannot know the output shape.

    raw(stage, *, allow_javascript=None) ¶

    Append a complete raw stage document ({"$limit": 3}).

    options(**opts) ¶

    Per-query options: allow_disk_use, max_time_ms, hint, collation, comment, batch_size.

    execute(*, raw=False) ¶

    Run on the synchronous driver and return a list of dicts (python field names).

    Fields¶

    Field types.

    Conversion pipeline¶

    to_python user/input value -> canonical Python value (lenient: "5" -> 5) validate canonical value -> raises :class:ValidationError on constraint breach to_mongo canonical value -> BSON compatible value (strict about types) from_mongo BSON value -> canonical Python value

    prepare_value (to_mongo(to_python(v))) is what filters use, which is why filter(name={"$ne": ""}) is rejected: a StringField can only ever produce a str.

    Field ¶

    Bases: Generic[T]

    Base class of all fields (also a descriptor on documents).

    pre_save(instance, adding) ¶

    Hook run by Document.save (auto_now & friends).

    validate(value) ¶

    Constraint validation of an already canonical, non-None value.

    clean(value) ¶

    Full cycle used by Document.full_clean: convert + validate.

    prepare_value(value) ¶

    Value as it must appear in a query (strict type, no constraints).

    lookup_field(lookup, value) ¶

    Field used to prepare value for lookup (lists delegate to their item field).

    AnyField ¶

    Bases: Field[Any]

    Accepts any BSON compatible value (operator-looking keys are refused).

    DecimalField ¶

    Bases: Field[Decimal]

    Exact decimals, stored as BSON Decimal128.

    DateTimeField ¶

    Bases: Field[datetime]

    Timezone aware datetimes, always normalised to UTC.

    Naive datetimes are assumed to be UTC.

    DateField ¶

    Bases: Field[date]

    Calendar dates (stored as midnight UTC datetimes - BSON has no date type).

    EnumField ¶

    Bases: Field[Enum]

    Stores Enum.value; accepts members or raw values.

    EmbeddedField ¶

    Bases: Field[Any]

    A document nested inside another (EmbeddedDocument subclass).

    ReferenceField ¶

    Bases: Field[Any]

    A reference to another document, stored as its primary key.

    post.owner returns the related object (cached by select_related / assignment, fetched on demand in sync code). post.owner_id is always the raw id.

    GeoPointField ¶

    Bases: Field[Tuple[float, float]]

    GeoJSON Point; the Python value is (longitude, latitude).

    Expressions¶

    Composable query condition (immutable).

    Q(age__gte=18) & ~Q(banned=True) | Q(role="admin")

    resolve(ctx) ¶

    Query-language form for find/$match.

    resolve_expr(ctx) ¶

    Aggregation-expression form (for $cond, $filter, $lookup pipelines).

    Bases: Expression

    Reference to a field: F("price"), F("owner__name"), F("items").

    Paths follow the model schema (python names, __ separator) and are validated when compiled. Use :class:Var for $$variables.

    Bases: Expression

    Generic {"$op": [args...]} expression. Subclass or use directly::

    Func("$toUpper", "name")

    Testing helpers¶

    Helpers for testing code that uses Aggify (pytest friendly, framework agnostic).

    from aggify.testing import capture_commands, assert_num_queries, assert_pipeline, temporary_database

    assert_pipeline(queryset_or_pipeline, expected) ¶

    Compare the compiled stages with expected (readable diff on failure).

    assert_query(queryset, **expected) ¶

    Assert on the find spec of a queryset, e.g. assert_query(qs, filter={...}, limit=5).

    temporary_database(uri, *, alias='default', prefix='aggify_tmp') ¶

    Connect to a throw-away database and drop it afterwards.

    Command monitoring: capture_commands() is Aggify's assertNumQueries.

    from aggify.testing import capture_commands, assert_num_queries

with capture_commands() as cmds:
    list(Post.objects.select_related("owner"))
assert cmds.names == ["aggregate"]

with assert_num_queries(1):
    Post.objects.count()

    The listener is attached to every client Aggify creates; it is a no-op unless a recorder is active.

    assert_num_queries(expected, *, names=None) ¶

    Fail unless exactly expected commands (optionally only those in names) hit the server.

    Exceptions¶

    Exception hierarchy.

    Everything raised on purpose by Aggify derives from :class:AggifyError, so a single except AggifyError is enough to catch library errors in a web handler or a gRPC servicer.

    AggifyError ¶

    Bases: Exception

    Base class of every Aggify exception.

    SynchronousOnlyOperation ¶

    Bases: AggifyError

    A blocking call was made from inside a running event loop.

    ValidationError ¶

    Bases: AggifyError

    Raised when a value does not satisfy a field.

    errors maps a field name to a list of messages, which makes the exception trivial to serialise into an HTTP 422 / gRPC INVALID_ARGUMENT.

    ObjectDoesNotExist ¶

    Bases: AggifyError

    Base of every per-model DoesNotExist.

    OptimisticLockError ¶

    Bases: AggifyError

    The document was modified by someone else since it was loaded.

    SecurityError ¶

    Bases: AggifyError

    A query/value was rejected because it looked like an injection attempt.
